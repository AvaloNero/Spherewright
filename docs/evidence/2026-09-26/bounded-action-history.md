# Bounded normal-action receipts and active-work index

The normal coordinator retained every action indefinitely and enumerated that history during each game frame. The new store separates active work from historical terminal receipts. Frame updates and competing-action checks use the active index; historical receipt expiry is request/admission-time maintenance, not a full-history frame scan.

Ordinary terminal results are retained for the configured `IdempotencyRetentionMinutes` **after completion is observed**, at least as long as their acceptance-time idempotency window. Active work, unknown/reconciled-unknown evidence, recovery-required actions, unsuccessful ordinary/blueprint construction and any checkpoint-bound flight remain protected. This includes a construction interrupted by session loss even if its state is `action_failed`, not `outcome_unknown`. Flights are conservatively pinned for the process lifetime, including successful ones; this slice does not infer checkpoint retirement from disappearance of a token.

The configured `MaxIdempotencyEntriesPerSession` value also bounds this normal-action store across the Plugin process. When full after safe expiry, it returns `SERVER_BUSY` before idempotency admission, token consumption or native execution; it never drops protected/unexpired evidence to make space. Existing plan expiry, state-hash validation and idempotency semantics are unchanged. An expired receipt is not permission to replay an action.

Scope: normal actions only, not a promise that every other coordinator's records have identical retention. Offline tests cover refusal without eviction, completion-relative expiry, idempotency overlap, active/protected preservation, duplicate identity, clock rollback and constant active-only frame traversal. No cold deployment or live load/throughput measurement is claimed.

Validation: seven new Core cases; complete Release build (including the Plugin against the current local game references) has zero warnings/errors. All 2241 offline tests pass: 1999 Core, 59 Contracts and 183 MCP. Independent Sol review accepted the adapter ordering and protection predicates. This does not change the installed `f4fc8e5` cohort or add a public MCP tool. Existing action-result description and packaged playbook now warn about receipt retention and prohibit inferring non-execution from missing history.
