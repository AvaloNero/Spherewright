## 0.3.2

- New Agent-created worlds now use `Spherewright_New_*`; imported player-save copies remain `Spherewright_Imported_*`.
- Legacy `Spherewright_M0_*` saves remain compatible with exact protected resume. Ownership never depends on a filename prefix.
- Added a packaged and MCP-discoverable opening-movement playbook for bounded recovery from landing-base and local-obstacle stalls.
- Move stall results now include structured failure and recovery fields instead of relying on message text alone.
- Documented the supported new-world and explicitly confirmed player-save import flows.

The release package was validated from a fresh peaceful, non-sandbox, 1× world through powered mining, smelting, automatic components, and sustained automatic Electromagnetic Matrix output. Cross-computer live validation of the explicitly confirmed save-import flow remains outstanding.
