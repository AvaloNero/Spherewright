## 0.4.0

- Added bounded multi-planet production, power, logistics, and research summaries for external Agents.
- Added native 600-tick production windows, runtime-derived theoretical capacity and utilization, and structured root-cause classification.
- Added same-planet and cross-planet upstream tracing through belts, sorters, splitters, and logistics stations.
- Added a privacy-allowlisted same-tick Overseer diagnostic bundle and protected per-save logistics progress windows.
- Retained the conversation-confirmed save-import boundary and all existing normal-game write safeguards.
- Bound newly issued protected resume tickets to each save's durable journal checkpoint, rejecting missing, recreated, or truncated timelines before gameplay can continue.
- Added a read-only Foundry material draft using runtime recipes and machine speeds, with shared-input demand, machine/power budgets, explicit supplies/byproducts and an explicit non-executable boundary.

This is an in-development changelog, not a complete release candidate. The owner merged the original Foundry (0.5) and Governor (0.6) scopes into 0.4 to prepare for interstellar expansion. The read-only Foundry material draft is implemented, but complete construction/resume, existing-line expansion and departure readiness are not yet accepted.
